# Security policy

OJU Video Forge is experimental and is not production ready. Do not use it to store
or process sensitive media or credentials.

## Reporting a vulnerability

Do not publish exploit steps, credentials, private media, or sensitive logs in a
public issue. Use the repository's private vulnerability reporting feature when
available. Otherwise, contact the repository maintainers privately through GitHub
and provide a minimal sanitized report.

Include affected versions/commit, impact, prerequisites, and a safe reproduction
summary. Allow maintainers time to investigate and coordinate a fix before public
disclosure. Do not test against systems or infrastructure you do not own or have
explicit permission to assess.

## Scope and expectations

Security reports about authentication/authorization, project or artifact access,
uploads, subprocess execution, dependencies, containers, and CI are welcome.
Automated scans and this policy do not imply that the application is secure or
production-ready. Keep local services private and do not use real user media in
public reports.
